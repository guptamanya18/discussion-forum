# Advanced Real-Time Discussion Forum

## Project Overview

This project is a scalable discussion platform that allows users to communicate and collaborate in real-time.

The system supports:

- User authentication
- Threaded discussions
- Real-time messaging
- Notifications
- Search functionality
- Role-based access control

The project is built using modern backend technologies including FastAPI and WebSockets.

---

## Tech Stack

Backend:
FastAPI

Real-Time Communication:
WebSockets

Database:
SQLite

Authentication:
JWT (JSON Web Token)

ORM:
SQLAlchemy

Server:
Uvicorn
